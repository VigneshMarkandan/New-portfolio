# Vignesh Markandan — Software & AI Engineer Portfolio

A modern, high-performance developer portfolio built with **React.js** and **Vite**, featuring custom CSS aesthetics, glassmorphism UI elements, dark mode styling, and responsive engineering case studies.

![Portfolio Preview](https://res.cloudinary.com/clt3bc7w/image/upload/v1785684249/svbfmjbcp2fsj5fc1tuv.jpg)

## ⚡ Tech Stack

- **Core**: React 18, JavaScript (ES6+)
- **Build Tool**: Vite 5
- **Styling**: Vanilla CSS3 (Custom Design System with CSS variables, Glassmorphism, Responsive Grid System)
- **Typography**: Sora, IBM Plex Mono, IBM Plex Sans (via Google Fonts)

---

## ✨ Features

- **Viewport-Fit Hero Section**: Optimized hero layout showcasing core technical skills, real-time availability status, and profile frame overflow effect.
- **Deep Technical Case Studies**:
  - `evolv-ai` — Autonomous agentic job application engine.
  - `LMS-Backend` — Learning management backend built around row-level authorization and quiz idempotency.
  - `Intelliguard-AI` — Real-time industrial PPE compliance detector powered by YOLOv8.
- **Interactive Stack Breakdown**: Domain-grouped technology tiles with custom visual icons.
- **Career Timeline**: Interactive track record of past roles and technical engineering contributions.
- **Smart Contact Links**: One-click direct email compose link fallback.

## 🛠️ Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/VigneshMarkandan/New-portfolio.git
   cd New-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
